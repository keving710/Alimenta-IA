# Notas de version v1.0.0 - Primera version educativa

- Registro y validacion de lotes (RF-01, RNF-01).
- Calculo de tasa de defectos, historial y filtro por producto (RF-02, RF-03).
- Tablero en linea de comandos (RF-04).
- Detector de lotes atipicos con IsolationForest y aviso de uso orientativo (RF-05).
- 18 pruebas pytest, datos sinteticos y dependencias fijadas.

Limitaciones conocidas: sin interfaz grafica, conjunto de datos pequeno, la IA solo ofrece apoyo analitico.
